# M-dulo-3-Power-BI-Financials
Projeto de análise financeira desenvolvido em Power BI como parte de desafio da DIO.
Repositório dedicado ao desenvolvimento do desafio prático do bootcamp Power BI Analyst pela DIO. O projeto consiste na criação de um relatório gerencial e interativo utilizando a base de dados Financial Sample.

---

Objetivo do Desafio
O propósito deste projeto é transformar dados financeiros brutos em insights estratégicos visuais, aplicando boas práticas de Design de Interface, estruturação de dados e interatividade por meio de recursos nativos do Power BI Desktop.
